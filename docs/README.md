# docs/

Project-wide documents and the traffic sign track (main). Traffic light documents are in
`traffic_lights/docs/`.

| File | What it holds |
|---|---|
| `decisions.md` | Dated decision log for the whole project (evaluator, licensing, where training runs, target change, repository layout). |
| `third_party.md` | Shared and traffic sign datasets, models and codebases, with license and source URL. |

Traffic sign surveys (datasets, OSS implementations) and replication notes will be added here as
`datasets.md`, `oss_implementations.md` and `replication.md`.

Conventions: English, no em dashes, every number maps to a config under `configs/` and a commit.
