# docs/

| File | What it holds |
|---|---|
| `datasets.md` | Survey of public traffic light datasets (sizes, labels, licenses, access, baselines) and the benchmark recommendation. |
| `oss_implementations.md` | Survey of open-source traffic light recognition code and weights, with a ranked list of replication candidates. |
| `replication.md` | What we replicated, the exact protocol, the measured numbers, and the GPU runs that remain. |
| `third_party.md` | Every dataset, model and codebase we build on or measure, with license and source URL. |
| `decisions.md` | Dated decision log. |

Conventions: English, no em dashes, every number maps to a config under `configs/` and a commit.
