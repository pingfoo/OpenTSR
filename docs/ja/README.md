# docs/

> 本文書は英語版 [docs/README.md](../README.md) の日本語訳である（原文 PR #7 `phase0-skeleton` 時点）。内容に食い違いがある場合は英語版を正とする。

プロジェクト全体に関わる文書と、道路標識トラック（主トラック）の文書を置く。信号機の文書は`traffic_lights/docs/` にある。

| ファイル | 内容 |
|---|---|
| `decisions.md` | プロジェクト全体の日付付き意思決定ログ（評価器、ライセンス、学習の実行場所、対象の変更、リポジトリ構成、標識ベンチマーク）。 |
| `third_party.md` | 共有および道路標識用のデータセット、モデル、コードベースの一覧（ライセンスと出典URL付き）。 |
| `datasets.md` | 公開されている道路標識データセットの調査（分類と検出、合成、VLM形式）、ライセンス、入手方法、日本向けデータの空白、ベンチマークの階層。 |
| `oss_implementations.md` | 2011年から2026年までのオープンソース道路標識認識のコードと重みの調査（古典手法、CNN、YOLO時代、量産スタック、Hub上のモデル）と再現候補。 |
| `vlm_and_foundation.md` | 標識を対象としたCLIP型ゼロショット、大規模マルチモーダルモデル、オープン語彙検出器、自己教師ありバックボーン、生成データ。 |
| `requirements_and_robustness.md` | 商用水準のTSRとは何か（EU ISA、Euro NCAP、日本）、ロバスト性ベンチマーク、敵対的攻撃と防御のコード、目標仕様の草案。 |
| `replication.md` | 標識について再現したもの、その厳密なプロトコル、測定値、残っているGPU実行。 |
| `dataset_catalog.md` | 代表的な標識データセットの図解カタログ（クラス定義とシード固定のサンプルを並べたもの）の生成物と、その再構築方法。 |
| `commercial_tsr.md` | 量産TSRシステムに関する調査メモ：文書化された根拠（特許、サプライヤーの論文、製品説明、ブラックボックステスト、SoCツールチェーン）、推定される検出・追跡・分類アーキテクチャ、そしてOpenTSRへの示唆。 |
| `benchmark.md` | ベンチマーク仕様の草案：3つの層（クロップ、フレーム、シーケンス中の標識通過イベント）、層ごとのデータとライセンス、評価指標、ロバスト性評価プロトコル、再実装するベースライン、報告ルール。 |
| `pipeline.md` | フェーズ0の成果物：実装された切り替え可能なパイプラインの骨格、最初のL3セットとしてのSTS（ライセンス確認、アノテーション形式、イベントファイル）、評価器の規約、模擬アブレーションによるハーネスの確認、フェーズ0の残作業。 |
| `system_design.md` | システム設計の草案：切り替え可能な量産相当のパイプライン（検出器、トラッカー、メモリ、分類器、リーダ、関連性判定、融合、判断、防御）、分類体系、展開コスト、クロップ・フレーム・イベントの各レベルでの敵対的評価、主張、リスク、フェーズ。 |

規約：英語で書き、em dashは使わない。すべての数値は `configs/` 配下の設定ファイルとコミットに対応づける。

日本語訳は `docs/ja/` に同じファイル名で置く。英語版が正であり、英語版を更新したら対応する日本語訳も更新する。
